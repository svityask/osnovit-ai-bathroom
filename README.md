# AI-дизайн ванной · Основит (прототип)

Страница, где можно задать параметры ванной и получить AI-визуализацию.
Синие точки на картинке показывают, где какой материал «Основит» используется.
Нажмите на точку: картинка плавно приблизится, а справа (на телефоне снизу)
откроется мини-окно с фото и названием продукта.

## Как это устроено

- Обычная статическая страница: `index.html`, `styles.css`, `app.js`, `products.js`. Ни сервера, ни сборки.
- Картинку генерирует открытая модель [FLUX.1-schnell](https://huggingface.co/spaces/black-forest-labs/FLUX.1-schnell) через публичный Hugging Face Space: бесплатно, без ключа, 3–10 секунд, запрос идёт прямо из браузера. У каждого посетителя свой суточный лимит GPU.
- Вкладка «Редактировать своё изображение» (как у PLITONIT): человек загружает фото ванной, выбирает быстрые правки или пишет своими словами, что поменять. Фото обрезается до 4:3 и уходит в [Qwen-Image-Edit-Fast](https://huggingface.co/spaces/multimodalart/Qwen-Image-Edit-Fast) (понимает русский, 8 шагов); запасной вариант [FLUX.1 Kontext](https://huggingface.co/spaces/black-forest-labs/FLUX.1-Kontext-Dev). На результат так же ставятся точки и подбираются материалы; ванна или душ определяются по картинке.
- Space вызываются через очередь Gradio (`callSpace()`), поэтому при ошибке видна причина, например исчерпанный лимит ZeroGPU и через сколько он восстановится.
- Картинки только от Hugging Face. Если он не ответил (кончился бесплатный лимит или сервер перегружен), страница показывает ошибку и кнопку «Попробовать ещё раз».
- Точки ставятся автоматически. Модель сегментации [SegFormer ADE20K](https://huggingface.co/Xenova/segformer-b0-finetuned-ade-512-512) скачивается с Hugging Face Hub и работает прямо в браузере через [transformers.js](https://huggingface.co/docs/transformers.js). Она находит на картинке стены, пол, ванну, стекло душевой, а `locateZones()` в `app.js` выбирает место для каждой точки:
  - стена и пол: самая «глубокая» точка области, подальше от краёв;
  - душ: середина области за стеклом; ванна: середина ванны;
  - примыкание: нижний край ванны или стекла, где они касаются пола или стены;
  - швы: второй участок плиточной стены.
- Первый раз модель грузится около 5 секунд (дальше берётся из кэша браузера), разметка занимает 2–5 секунд. Если сегментация не сработала, точки встают в запасные позиции. Любую точку можно перетащить.
- Продукты подбираются простыми правилами в `pickMaterials()` (`app.js`):
  - крупная плитка → эластичный клей;
  - глянец или мрамор → белый клей и эпоксидная затирка;
  - душ → гидроизоляция с лентой.
- 15 продуктов с фото и ссылками лежат в `products.js` (данные с osnovit.ru).

- При открытии страницы сразу виден интерактивный пример (`example.webp`, нарисован тем же FLUX на Hugging Face) с точками и подобранными материалами.

## Запуск локально

```bash
python -m http.server 8731
```

Откройте http://localhost:8731
