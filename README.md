# AI-дизайн ванной · Основит (прототип)

Страница, где можно задать параметры ванной и получить AI-визуализацию.
Синие точки на картинке показывают, где какой материал «Основит» используется.
Нажмите на точку: картинка плавно приблизится, а справа (на телефоне снизу)
откроется мини-окно с фото и названием продукта.

## Как это устроено

- Обычная статическая страница: `index.html`, `styles.css`, `app.js`, `products.js`. Ни сервера, ни сборки.
- Картинку генерирует открытая модель [FLUX.1-schnell](https://huggingface.co/spaces/black-forest-labs/FLUX.1-schnell) через публичный Hugging Face Space: бесплатно, без ключа, 3–10 секунд, запрос идёт прямо из браузера. У каждого посетителя свой суточный лимит GPU.
- Картинки только от Hugging Face. Если он не ответил (кончился бесплатный лимит или сервер перегружен), страница показывает ошибку и кнопку «Попробовать ещё раз».
- В запросе на генерацию задана композиция (вид от двери, мокрая зона слева, тумба справа, пол на переднем плане). Точки стоят в заранее известных зонах.
- Модель не всегда слушается композиции. Если точка промахнулась, её можно перетащить.
- Продукты подбираются простыми правилами в `pickMaterials()` (`app.js`):
  - крупная плитка → эластичный клей;
  - глянец или мрамор → белый клей и эпоксидная затирка;
  - душ → гидроизоляция с лентой.
- 15 продуктов с фото и ссылками лежат в `products.js` (данные с osnovit.ru).

## Запуск локально

```bash
python -m http.server 8731
```

Откройте http://localhost:8731

## Что дальше

- Своя модель генерации (качество, без водяного знака) через серверную функцию с ключом.
- Автопоиск зон на картинке через vision-модель вместо фиксированных координат.
- Режим «Редактировать своё изображение» и лимит попыток в сутки, как у оригинала.
- Правила подбора, проверенные технологом «Основит».
